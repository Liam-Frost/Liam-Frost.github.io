## 2. 现有页面如何归并

- 「外观与首页」的首页开关和登录背景移到对应子页；旧地址先保留跳转，避免收藏链接失效。
- 现有「API 配置」迁到「后台 → 集成与 API」，只整理界面与入口，不重新复制密钥。
- 「关于」里的宣言、器材，「联系我」里的联系方式，「技术栈」里的类别/条目仍是内容管理，不藏进设置。网站设置提供快捷入口。
- 收藏专属的展示、导入、播放器选项继续靠近收藏/播放器；全站设置不成为杂物抽屉。
- 审计日志继续只读；界面位置可归并，但不能从设置页修改或删除审计记录。

## 3. 主题、语言与内容的优先级

主题：访客保存的选择 → 站点默认 → 默认值为跟随系统；跟随系统时响应系统变化。管理员改默认值不覆盖已有访客选择。

语言：显式分享链接语言（若将来采用语言路由）→ 访客选择 → 站点默认；「自动识别」读取浏览器支持语言，最后回退英文。后台语言单独保存，不改前台语言。当前前台的现有行为要以兼容迁移测试为准。

显示：总开关开启 **且** 存在可见内容。作品只统计公开条目、技术栈只统计可见技术、联系方式只统计启用且有效的项目。无内容时显示「已开启 · 因暂无公开内容自动隐藏」，不自动把开关写成关闭。章节导航和锚点也使用同一份最终可见列表。

词典：保存稳定 key，翻译只影响显示，不改已有内容标识；回退顺序为当前语言 → 英文 → 原始标签。删除被引用的词条要阻止或先提供替换。不要允许通过翻译编辑 API 错误码、路由、安全提示含义。

## 4. 数据与接口

沿用现有 Setting 存储、校验和 revision 并发控制，按职责保存 `site.identity`、`site.footer`、`site.preferences`、`site.home`、`site.privacy`、`site.dictionary`、`admin.branding`、`admin.preferences`，而非新增一个巨型 JSON。已有 appearance 字段先兼容读取，再按分组迁移，重复迁移应幂等。

公开 API 只返回白名单投影；后台路径、账号、安全设置、集成密钥绝不出现在公开响应、HTML、静态快照或前台 bundle 中。身份认证与运行时配置仍使用专用服务，不直接存入通用 Setting。响应从不返回密码散列、密钥明文或恢复码。

设置更新必须经过管理员认证、CSRF、服务端 schema、字段长度/URL/文件类型校验、revision 校验；同一页冲突时展示最新版本与当前草稿，不静默覆盖。Logo 优先 PNG/WebP/AVIF；SVG 必须消毒或栅格化，禁止直接嵌入不可信 SVG。

设置变更记审计日志：操作者、时间、设置组、结果、版本及脱敏字段名；不记录密码、token、隐私正文或图片二进制。公开资源采用版本号失效缓存，区域节点只有与正式版本一致且健康才纳入路由，不能由独立设置写入绕过现有发布保护。

## 5. 高风险设置的专门流程

### 账号与密码

先验证当前密码，限速并记录成功/失败，密码新旧字段分离。成功后轮换会话、废止其他会话，明确告知重新登录行为。不能在改密码时更换用于集成密钥加密的根密钥。保留私有命令行恢复账号的运维入口；不能将恢复凭据放入公开文档。

### 后台路径

当前路径涉及前后端基址、认证 cookie 与代理/静态路由，不能只改一条数据库记录。建议第二阶段实现：预检保留路径与冲突 → 生成候选配置 → 重建/发布 → 验证新地址登录及 API → 切换 → 短暂保留受保护的旧地址跳转 → 自动移除。失败自动保留原入口，私有回滚路径必须可用。跳转不能带 cookie/token，也不公开列出真实后台路径。

第一阶段只显示「由运行配置管理」及说明，不给一个实际不生效的输入框。隐藏路径只是减少暴露，不能替代认证与限速。

### 登录安全

阈值提供经过测试的范围，禁止关闭所有保护；可信代理地址由运维配置管理，避免伪造 IP 绕过限速。TOTP 启用需验证验证码并下载一次性恢复码后才生效；关闭需重新验证。故障恢复不能只依赖正在修改的同一登录入口。

## 6. 页面交互

各页顶部一句说明与当前生效状态；表单字段旁放局部预览，底部固定保存条。危险操作使用明确的操作按钮，不和保存普通外观混在一起。上传显示尺寸、裁切与浅/深色预览；错误留住草稿。移动端先展示关键字段，提示文字可折叠，但不隐藏失败原因。

主页开关用紧凑列表：名称、内容数量、开关、最终状态、「编辑内容」；词典用可筛选的表格和侧滑编辑器，不一次展开所有语言输入框。后台全文国际化后，设置页标题、错误、验证信息、日期及审计事件描述都走稳定消息 key。

## 7. 环境与同步边界

正式站的公开内容可同步到 preview；preview 的统计开关、后台路径、管理员账户、API 密钥、登录安全与运维配置始终保留各自环境的值。公开前台设置是否随内容同步需逐项列入白名单，默认不复制整张 Setting 表。

首次迁移读取现有默认值与已保存值，生成差异报告；默认不覆盖现有照片、Logo、联系方式或统计选择。任何批量迁移都先备份和演练。应急站独立发布，不能因某个区域失败而跳过品牌/隐私更新。

## 8. 建议实施顺序与验收

1. **整理入口与公开设置**：复用现有外观/开关/API 页面，增加身份、头像、页脚、默认主题/语言、隐私。验收包括旧入口兼容、访客偏好优先、无内容隐藏、公开字段无泄漏、保存失败与并发冲突保留草稿。
2. **词典与后台基础国际化**：以收藏标签为首批，建立消息 key/复数/日期格式；完成后台语言才开放切换。验收五语缺译回退、同一标签身份不变化。
3. **账号与安全管理**：重新认证、改密与会话撤销、TOTP/恢复码、脱敏审计，覆盖错误密码、限速、会话过期及恢复流程。
4. **后台地址切换**：最后单独做发布级切换，覆盖候选失败、验证失败、回滚和旧入口退役；不与前三阶段捆绑上线。

阶段 1 已按授权推进；阶段 3、4 仍分别评审，不会因保存普通设置而改变账号、地址或生产密钥。

## 9. 第一阶段实际交付

- 网站设置分前台/后台：基本资料、公开图库头像、独立 Logo 与替代文字、首页板块及公开内容数量、页脚署名、主题/语言初值、多语言隐私和标签词典；后台保留登录背景与 API 集成；统计设置和只读审计入口独立于网站设置。旧外观/API 地址保留跳转及回调参数。
- favicon 独立设置，采用本站托管的公开图库图片，生成 32/180/192/512 PNG 与 ICO，使用内容版本号缓存；同时用于前台和后台登录页。应急构建只读公开品牌与图标，不读取后台配置。
- 身份、页脚、偏好、隐私、词典和图标按 `site.*` 分组保存；已有 Logo/登录背景/首页开关继续沿用 presentation 存储，不做覆盖式数据搬迁。无新增 SQL 迁移。空值保留原站默认内容。
- 每组独立 revision 和校验；保存失败保留草稿。409 冲突读取最新值并展示两份内容，管理员选择保留草稿后仍需再次点保存。离开未保存页面有提示。隐私保留最近十个已保存版本，恢复先填入草稿。
- 词典沿用稳定 ID/原始别名，保护已被公开或私有收藏引用的别名；展示优先使用条目自身现有翻译，再用词典当前语言、英文和原标签。此阶段只管理收藏标签，不编辑所有界面文案。
- 公开设置必须成功读取才呈现页面，失败提供重试，避免悄悄显示过期隐私或管理员未选择的默认值。访客已有主题/语言选择优先；站点初值不伪装成访客选择写入本地存储。
- preview 仅同步明确列举的公开 `site.identity/footer/preferences/privacy/dictionary/favicon` 与既有 collection 设置；不复制隐私历史、集成密钥、账号、安全、后台路径或 preview 统计开关。混有后台外观的 presentation 设置继续保留环境本地值。
- 账号与安全页当前仅展示受保护运行配置的状态；后台语言仍为简体中文。在线改密、会话管理、TOTP、后台地址切换及完整后台国际化尚未交付，不展示无效编辑控件。

本地验证覆盖 API 权限/CSRF、分组并发、公开投影、历史版本、私有条目引用保护、图标生成和隐藏图片拒绝；浏览器覆盖手机/桌面、保存失败、并发比较、独立 Logo、偏好优先、词典、隐私 HTML 隔离及设置读取失败恢复。实际发布仍遵循原有 CI、候选校验和人工生产审批。
