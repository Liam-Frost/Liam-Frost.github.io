# Admin

## Current Scope

Stage 3 adds the authentication foundation for the future management backend.

Current admin features:

- Hidden front-end route: `/admin`.
- API session check: `GET /api/admin/session`.
- API login: `POST /api/admin/login`.
- API logout: `POST /api/admin/logout`.
- Reusable backend guard: `requireAdmin()`.

Photo CRUD, uploads, project management, and media collection management are intentionally deferred to later stages.

## Configuration

Generate a password hash:

```bash
npm run auth:hash -- your-password
```

Set the API environment values in `apps/api/.env`:

```txt
ADMIN_USERNAME=liam
ADMIN_PASSWORD_HASH=scrypt:v1:...
ADMIN_SESSION_SECRET=replace-with-a-long-random-secret
ADMIN_SESSION_TTL_SECONDS=28800
# DEVELOPMENT ONLY. Use true in production behind HTTPS.
ADMIN_COOKIE_SECURE=false
```

For production, set `ADMIN_COOKIE_SECURE=true` and serve the site over HTTPS.

## Session Model

The API uses an HttpOnly cookie named `lf_admin_session` by default. The cookie contains a signed HMAC session token with an expiration timestamp.

The password is not stored in plaintext. The accepted password format is a `scrypt` hash generated by `npm run auth:hash`.

Login attempts are rate-limited in memory by client IP. Logout clears the browser cookie and revokes the current session token in memory until its original expiration.
