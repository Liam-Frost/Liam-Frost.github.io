# 执行计划：首页收藏区块（Stage 21）

状态：已确认，已完成（Stage 21）。

## 目标

首页的收藏区块原来只有「最近在看」一行（6 部电影、剧集或动漫）。改为能体现整个收藏：精选放在最前面，然后是正在进行和最近完成，篇幅有上限。

## 设计

区块标题下面一行数字：今年看完几部、读完几本、玩过几款（只统计今年有完成日期的条目；没有时显示一句简介），点击进入收藏的「回顾」。

从上到下：

| 板块     | 桌面                          | 手机                  | 内容                                                     |
| -------- | ----------------------------- | --------------------- | -------------------------------------------------------- |
| 精选     | 3 张大卡片                    | 横向滑动              | 封面、标题、类型、评分、短评摘录                         |
| 正在进行 | 1 行，最多 4 个               | 最多 2 个             | 在看 / 在读 / 在玩，带进度（集数、页数、卷数、游戏时长） |
| 最近完成 | 1 行（6 个）；没有精选时 2 行 | 3 个；没有精选时 6 个 | 可按「全部 / 影视 / 阅读 / 游戏」切换                    |
| 在听     | 1 条窄栏                      | 1 条窄栏              | 一个歌单，可以直接在右下角播放器播放                     |

规则：

- 同一个条目只出现一次：精选里的条目不再出现在正在进行和最近完成里。
- 没有内容的板块隐藏；精选只有 1 到 2 个时按实际数量显示，不拿其他条目补。
- 静态构建（没有 API）时整个区块和以前一样隐藏。

### 精选的顺序：两种方式，在收藏的「显示设置」里切换

- **自动轮换**（默认）：按日期轮换，每天展示不同的 3 个，同一天所有访客看到的一样（日期按 `ANALYTICS_TIMEZONE` 的时区）。选的时候先让类型不重复（电影、书、游戏……各一个），再按顺序补满。
- **固定顺序**：按后台拖动排好的顺序，取前 3 个。新标为精选、还没排过的条目排在已排序的后面。

### 后台

- 收藏页新增「首页精选」按钮：列出所有标为首页精选的条目（各种类型在一起），可以拖动或用上下按钮排序，保存后用于固定顺序。对话框里写明当前使用的是哪种方式。
- 「显示设置」增加「首页精选：自动轮换 / 固定顺序」。

## 实现

- 数据库：`MediaItem` 新增 `featuredOrder`（可空整数），新迁移 `20261109090000_media_featured_order`。排序直接写这一列，不改条目的更新时间。
- 设置：`CollectionSettings.homeFeatured: "rotate" | "manual"`，旧的设置没有这一项时按自动轮换处理（不会丢失其他设置）。
- 接口：
  - `PUT /api/admin/media/featured-order`：`{ ids }`，必须正好是全部精选条目。
  - `/api/collection` 增加 `home.featured`：服务器按设置选出的最多 3 个精选（id 和短评摘录）。摘录只给这几个条目，取短评开头一两句。
- 网站：首页收藏区块拆成独立组件；所有新文字五种语言都要有。
- 测试：轮换（同一天固定、隔天变化、类型分散）、固定顺序、排序接口校验、旧设置兼容、摘录长度。

## 不做

- 首页其他区块（项目、照片精选）不变。
- 不做访客自己切换精选。
